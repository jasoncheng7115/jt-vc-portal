# Security Policy

## Supported Versions

Only the latest release receives security fixes. Please upgrade before reporting.

## Reporting a Vulnerability

Please do not open a public issue.
Use GitHub "Report a vulnerability" (Security tab), or email service@jason.tools.
We aim to acknowledge within 3 business days and to release a fix and
publish a GitHub Security Advisory within 7 days for confirmed issues.

## Security Advisories

Published advisories: https://github.com/jasoncheng7115/jt-vc-portal/security/advisories

## Software Bill of Materials (SBOM)

Every Release (from v1.25.3) includes two CycloneDX 1.5 SBOM files, so you can check the
components against new vulnerability reports with tools such as Dependency-Track, Trivy or Grype:

- `jt-vc-portal-X.Y.Z-sbom.cdx.json` — application: the third-party parts the portal uses
  (bundled Jitsi IFrame API and PDF font; Chart.js, flatpickr and qrcodejs loaded from a CDN with
  Subresource Integrity) with versions, hashes and licences. The PHP code has no third-party packages.
- `jt-vc-portal-X.Y.Z-image-sbom.cdx.json` — the Release Docker image: PHP, Apache and the Debian packages.

Both are generated by GitHub Actions from the tagged source when the Release is built
(`tools/make-sbom.py` and syft).
